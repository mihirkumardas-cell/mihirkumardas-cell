### 🗑️ [BinGO — AI Waste Reporting & Dispatch Platform](https://github.com/mihirkumardas-cell/BinGO)

- `FastAPI` + `PostgreSQL/PostGIS` (SQLAlchemy 2.0 async + GeoAlchemy2) for geospatial queries
- `YOLOv8n` waste detection + `DBSCAN` hotspot clustering + urgency scoring
- `Redis`/`arq` async job queue, MinIO object storage, JWT auth (RBAC)
- Firebase (FCM) push + Twilio SMS fallback, Nginx reverse proxy, Docker Compose stack, CI/CD via GitHub Actions
